# Brewmaster tank replay

The Patchwerk DPS reference and native DPS fixture are not a like-for-like intake scenario. The pinned reference has an attacking `Fluffy_Pillow` with melee, melee nuke, bleed and tank healing; mean damage taken is 9.33M. The native DPS fixture uses passive dummy 31146 and sampled health remains full. Their talent strings and equipped item IDs match; the native literal APL identifies the pinned MID2 profile, but no reference profile-hash proof was found. Therefore the observed DPS gap is not by itself a parity result.

The SimC dungeon-dummy scenario uses a level-92 attacker, difficulty 23, content tuning 3025 and MythicPlusSeason 120. ExpectedStatMod 448 supplies its armor coefficient; older measurements below predate this scenario correction. The earlier 3.233M versus 3.318M damage-taken match hid compensating errors: after the scenario correction, the native mean was 3.722M. The remaining excess is not yet attributed to a specific mechanic.

- [x] Blackout Kick grants the selected Blackout Combo buff. Tiger Palm and Keg Smash consume it; unrelated casts must not consume it, and their melee events must not grant it again.
- [x] Bring Me Another's chance-based Empty Barrel proc accepts Brew casts, not unrelated attacks. The separately selected guaranteed trigger remains active.
- [x] Fortifying Brew snapshots max-health gain from the selected talent's native effect, not its visible action.
- [x] Purifying Brew uses its modified Stagger-clear percentage, including selected Mantra of Purity.
- [x] Quick Sip carries applied Shuffle duration across extensions and clears its selected percentage of the live Stagger pool at each threshold.
- [x] Blackout Kick impacts and incoming physical hits, including the dummy bleed's application and ticks, grant Elusive Brawler. Tiger Palm, Keg Smash and self-Stagger do not. A dodge consumes its stacks unless selected One With the Wind preserves them; a miss does not consume them.
- [x] Base and bonus Agility contribute to gameplay dodge with the sourced class-specific diminishing returns.
- [x] Selected Elusive Footwork adds its native extra mastery stacks on critical Blackout Kick impacts.
- [x] Selected Sal'salabim's Strength resets Breath of Fire cooldown when Keg Smash is cast.
- [x] Invoke Niuzao uses its native enemy target so the literal APL can cast it.
- [ ] Compare all Brewmaster casts, mitigation, healing and absorbs against the pinned MID2 SimC dungeon-dummy trace. Qualify remaining differences with native combat tests.

On seed 70448, a single SimC iteration took 1,738,562 direct damage after Stagger (swing 498,764, strike 601,943, bleed 637,855) and 1,296,543 Stagger ticks. SimC ticks totaled 1,729,469 before mitigation. SimC applies versatility and damage-taken buffs such as Fortifying Brew to each tick again. Native 124255 has `SPELL_ATTR4_IGNORE_DAMAGE_TAKEN_MODIFIERS`, and TC `Unit.cpp:7048–7052` skips versatility for it. The pooled damage was already mitigated, so this is a SimC double application.
