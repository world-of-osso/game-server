# Holy Paladin replay

- The pinned SimC source rejects Holy Paladin and has no default Holy healing action list. The native replay maintains one healer-owned Beacon on the party instead of moving it to each injured target, uses deficit-gated healing and emergency cooldowns, and uses admitted damage actions against the tank's enemy when no heal is selected.
- The policy uses Avenging Wrath on cooldown. Native talent 1241288 empowers Judgment through override aura 1241410 during Avenging Wrath. The MID2 Holy profile replaces Crusader Strike with Holy Shock and does not know Consecration.
- The canonical tank-only replay measured 29.42% idle GCD time; this build has no other admitted damage filler.
