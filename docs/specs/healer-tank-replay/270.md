# Mistweaver Monk replay

- The pinned SimC default action lists do not include Mistweaver. The replay uses native readiness and party health to select healing actions.
- Renewing Mist requires a health deficit. When Vivify resolves to the group heal Sheilun's Gift, its heal-worthwhile gate uses the total living-party deficit; single-target Vivify uses its target's deficit. When no healing action is admitted, the policy uses Rising Sun Kick, Blackout Kick or Tiger Palm against the tank's enemy.
